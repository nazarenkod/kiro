# lessons — уроки gen-test (від reflection)

Стартово **порожній**. Наповнюється наприкінці сесій через скіл `reflection`:
уроки, специфічні для генерації тестів (евристики мапінгу case → ресурси,
типові падіння і їх класи, платформні нюанси iOS, скрол-патерни, колізії
стабів), йдуть **сюди**, а не в `conventions.md`.

`conventions.md` — **недоторканний**: автозаписи агента туди не потрапляють.
Дрейф довідника відносно кодової бази закривається тим самим reflection:
урок «компонент X поводиться інакше» → сюди; правки самого `conventions.md` —
лише руками.

Кількісний вхід для reflection — метрики (розділ 6 `DESIGN.md`): розподіл
`failure_classes` і частка `scroll_fix` кажуть, які правки скіла дадуть
найбільший ефект.

---

## Формат уроку

```
### <дата> · <checkId/блок> · <клас: locator|scroll|stub|data|flow|env|codegen|plan>
**Симптом:** <що сталося>
**Причина:** <корінь>
**Урок / правка:** <що робити інакше; за потреби — у який reference внести>
```
